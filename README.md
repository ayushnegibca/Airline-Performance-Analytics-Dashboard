# Airline Performance Analytics Dashboard

## Project Overview
This is a comprehensive airline performance analytics dashboard created using **Power BI** and **Excel**. The dashboard provides insights into flight operations, safety metrics, and performance indicators across different routes and airlines.

## Motivation
This project was inspired by a critical incident involving an Ahmedabad to London flight. The accident highlighted the importance of data-driven insights in monitoring airline performance and identifying potential risks. This dashboard serves as a tool to analyze flight data and track key performance indicators that can contribute to safer and more efficient aviation operations.

## Tools & Technologies
- **Power BI** - For interactive visualizations and dashboard creation
- **Excel** - For data preparation, cleaning, and analysis

## Key Features
- Performance metrics tracking across routes
- Flight safety and operational data analysis
- Real-time dashboard visualizations
- Historical data trends and comparisons

## How to Use
1. Clone this repository
2. Open the Power BI dashboard file
3. Review the Excel data sources for understanding the dataset
4. Interact with the visualizations to explore insights

## Data Sources
The dashboard uses airline performance data including flight routes, safety metrics, delay information, and operational statistics.
